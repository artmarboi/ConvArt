## 🚀 Возможности

- **Конвертер медиа**:
  - Видео: MP4, MKV, MOV, WebM, AVI и др.
  - Аудио: MP3 (до 320 kbps), FLAC (Lossless), WAV, AAC/M4A, OPUS, OGG.
  - Графика: WebP, AVIF, PNG, JPG с контролем качества и сжатия.
  - Аппаратное ускорение GPU: **NVIDIA NVENC**, **AMD AMF**, **Intel QSV**.
  - Пресеты сжатия: Ультра-сжатие, Сбалансированный, Высокое качество, Discord 8MB/50MB.

- **Загрузчик медиа из сети (DoH yt-dlp)**:
  - Поддержка YouTube (до 4K/2K/1080p), SoundCloud, TikTok, VK Видео, Spotify и 100+ сайтов.
  - Встроенный обход замедлений и DNS-блокировок через прямой DoH-резолвер (1.1.1.1 / 8.8.8.8).
  - Автоматическое вшивание тегов исполнителя, трека и обложек альбомов в скачиваемые файлы.
  - Очередь загрузок с параллельным или поочередным скачиванием.

- **Автономность и обновления**:
  - Полная автономность: не требует установки Python, Node.js или FFmpeg пользователем.
  - Встроенный центр автообновлений через GitHub Releases в 1 клик.

## 🛠️ Разработка и сборка

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки (Hot-Reload)
npm run dev

# Сборка дистрибутивов (Installer Setup, Portable .exe)
npm run build
npx electron-builder --win
```
